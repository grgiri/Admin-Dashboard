# Admin Dashboard

A responsive admin dashboard built with HTML and CSS as part of [The Odin Project](https://www.theodinproject.com/) Intermediate HTML and CSS curriculum.

## Live Preview

🔗 [View Live](https://grgiri.github.io/Admin-Dashboard/)

## Built With

- HTML5
- CSS3 (Grid & Flexbox)
- SVG Icons from [Material Design Icons](https://pictogrammers.com/library/mdi/)

## Features

- Three-region layout using CSS Grid — sidebar, header, and main content
- Sidebar with navigation links and settings group pushed to the bottom
- Header with search bar, user info, greeting, and action buttons
- Project cards with a yellow left border accent and action icons
- Announcements section with divider-separated items
- Trending section with avatar, username, and tagline rows

## What I Learned

- Setting up a full-page CSS Grid layout with `grid-template-columns` and `grid-template-rows`
- Using `grid-row: 1 / 3` to make the sidebar span the full height
- Nesting Grid and Flexbox containers within each other
- Scoping CSS selectors to prevent style bleed across sections
- Using `margin-top: auto` to push elements to the bottom of a flex container
- Using `grid-column: 1 / -1` to span an element across all grid columns
